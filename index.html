사용 안내 (예시 화면)

HWP, HWPX 파일을 광고 없이 바로 확인하세요

위의 파일 열기를 누르고 카카오톡 받은 파일, 다운로드 폴더 등에서 한글 문서를 고르면 본문이 여기에 표시됩니다.

지원

HWP(한글 2002 이후), HWPX

표시되는 것

본문 글자, 표, 글상자 안 글자, 각주

표시 안 되는 것

그림(자리만 표시), 글꼴·색·쪽 배치, 머리말·꼬리말

보안

파일은 서버로 올라가지 않고 이 기기 안에서만 열립니다.

카카오톡에서 바로 열기: 이 페이지를 앱으로 설치한 뒤, 카톡 파일을 길게 눌러 공유 → 한글뷰어를 고르세요.

암호가 걸린 문서와 배포용 문서는 본문을 풀 수 없어서, 문서에 들어 있는 미리보기 글자만 보여 드립니다.

본 제품은 한글과컴퓨터의 한/글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.
